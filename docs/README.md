# 🦁 Virtual Zoo – Virtual Reality Application

## Project Overview

Virtual Zoo is an immersive Virtual Reality application developed using Unity 3D and Oculus Quest 2. The application allows users to explore a virtual zoo environment, interact with animals, and experience realistic habitats through VR technology.

This project was developed as a final-year academic project.
